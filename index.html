about

Two years deep in the plumbing of a stock exchange.

I work as a Junior Software Engineer at Geojit Technologies, where I build the enterprise applications that power trading, accounts, depository and Margin Trading Facility workflows for a real brokerage. That means writing Angular components that traders and back-office staff use daily, and SQL Server logic that has to be correct every single time — there's no room for a rounding error in a contract note.

Before that, I built patient management and messaging tools for a healthcare product, which is where I first learned to move fast on Angular and REST APIs. Between the two, I've picked up a habit of chasing production issues to their root cause rather than patching symptoms, and optimizing SQL until the numbers actually move — one recent pass cut stored procedure runtime by up to 30%.

I hold an MCA from Government Engineering College, Thrissur, and I'm comfortable moving across the stack — Angular and TypeScript on the front end, Java and Spring Boot on the back end, SQL Server where the real business rules live.
