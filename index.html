about

Turning specs into software people rely on.

I work as a Software Engineer at Geojit Technologies, building enterprise-scale applications end to end — Angular on the front end, Spring Boot for services, Microsoft SQL Server for the data and business logic underneath. My day-to-day is reusable components, REST integrations, and stored procedures that need to hold up under real production load.

Before that, I built patient management and messaging tools for a healthcare product, which is where I first learned to move fast on Angular and REST APIs. Across both roles I've picked up a habit of chasing production issues to their root cause rather than patching symptoms, and optimizing SQL until the numbers actually move.

I hold an MCA from Government Engineering College, Thrissur, and I'm comfortable moving across the stack. Most of my production experience so far has been in fintech, which you'll see highlighted in the projects below.
